# 🌿 FloraGuard AI - Plant Disease Detection Web Application

## 📌 Project Overview
FloraGuard AI is an AI-powered web application that helps detect plant diseases from leaf images. The system uses deep learning techniques to classify plant diseases and provide prediction results.

## 🚀 Features
- Upload plant leaf images
- AI-based disease prediction
- Supports multiple plant disease classes
- Disease information and history tracking
- User-friendly web interface

## 🛠️ Technologies Used

### Frontend
- React 19
- TypeScript
- Tailwind CSS

### Backend / AI
- Python
- Flask
- TensorFlow / Keras
- CNN (Convolutional Neural Network)
- OpenCV

## 📂 Project Structure
Frontend - React application  
Backend - Flask API  
Machine Learning Model - CNN based plant disease classification model  

## 🎯 Objective
The main objective of FloraGuard AI is to identify plant diseases using artificial intelligence and help users detect diseases at an early stage.

## ▶️ How to Run the Project

### Frontend
```bash
npm install
npm run dev
```

### Backend
```bash
pip install -r requirements.txt
python app.py
```
